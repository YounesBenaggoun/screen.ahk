# 📺 Screen.AHK

> AutoHotkey utility for screen & mouse automation with advanced shortcut handling

![AutoHotkey](https://img.shields.io/badge/AutoHotkey-v2.0-blue)
![License](https://img.shields.io/badge/license-ISC-green)
![Version](https://img.shields.io/badge/version-1.0.0-orange)

---

## ✨ Features

- 🖱️ **Smart Mouse Control** - Center mouse, custom positioning, and movement
- ⌨️ **Triple Key Detection** - Advanced keyboard shortcut handling (single, double, triple clicks)
- 🔄 **CapsLock Toggle** - Quick toggle functionality
- ⏱️ **Millisecond Timestamp** - Precise timing utilities
- 📊 **Debug Printer** - Rich object/array/map printing for development
- 🎯 **Flexible Configuration** - Easy to extend and customize

## 🚀 Installation

### Prerequisites

- [AutoHotkey v2.0+](https://www.autohotkey.com/)
- [Node.js 22.12+](https://nodejs.org/) (for commitlint & husky)
- Git

### Clone & Setup

```bash
# Clone the repository
git clone https://github.com/YounesBenaggoun/screen.ahk.git
cd screen.ahk

# Install dependencies (for development tools)
npm install

# Initialize husky for git hooks
npm run prepare
